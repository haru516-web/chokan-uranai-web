# Vercel の持ち主の方へ：公開のお願い

「潮環占い」（占いのWebサイト）を、あなたの Vercel で公開してください。サイトの運営と、売上の受け取りは、尾花さんが行います。あなたには、ホスティング（サイトを置く場所）と、設定をお願いします。

> **このファイルには、秘密のキーを書きません。** Stripe のキーは、別の方法で、一度だけお渡しします。チャット・メール・GitHub・スクリーンショットに、キーを、残さないでください。

## 0. 先に確認してほしいこと

- Vercel のプランが **Pro** であること。利用者に課金するサービスは、Hobby（無料）プランでは、規約上、使えません。
- 取り決め：アカウントが止まったときや、請求のこと（Vercel の料金は、あなたの負担）を、尾花さんと、先に話しておいてください。

## 1. サイトを公開する（まず、課金なしで）

1. GitHub で、`haru516-web/chokan-uranai-web` を、自分のアカウントに **Fork**（コピー）します。
2. Vercel で、Add New → Project → コピーしたリポジトリを選び、**そのまま Deploy** します（設定は、自動で入ります）。
3. 公開URLを開いて、次を確認します。
   - `/` が開く（アプリ）
   - `/questions/`、`/about/`、`/terms/`、`/privacy/`、`/tokushoho/`、`/refund/` が開く
   - `/sitemap.xml` と `/robots.txt` が開く
   - `/api/config` を開くと `{"billing":false,…}` と出る（この段階では、課金は、まだ動きません）
4. 出来たら、尾花さんに、公開URLを連絡してください。

## 2. 有料版を動かす（テストモードで、先に確認）

Vercel の Settings → Environment Variables に、次を入れます。**値は、保存したあと、見えなくなる「Sensitive」にしてください。** 環境は、Production と Preview の、両方にチェックを入れます。

| 名前 | 値 |
|---|---|
| `STRIPE_SECRET_KEY` | 尾花さんから、**別の方法で**受け取ったキー（`rk_test_…`） |
| `STRIPE_PRICE_ID` | `price_1Uc1mY3Lj6CS9ZKsk0rsei2K`（テスト用の価格のID） |
| `ENTITLEMENT_SECRET` | ご自身で作る、長いランダムな文字列（下の方法） |

`ENTITLEMENT_SECRET` の作り方（どちらか）：

```
openssl rand -hex 32
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

入れたら、**まず `VITE_BILLING` は、入れずに**、再デプロイします。

1. `/api/config` を開いて、`{"billing":true,…}` になっていることを確認します。
2. 設定画面（右上の歯車）が、「無料版をご利用中です」ではなく、有料の枠が、すべて開いたままであることを確認します（まだ、`VITE_BILLING` が、ないためです）。
3. 尾花さんに、「ここまで済みました」と連絡します。テストの手順は、尾花さんから、お伝えします。

## 3. 有料の枠を閉じる（テストが通ったあと）

尾花さんの「OK」の連絡のあとで、`VITE_BILLING` に `1` を入れて、再デプロイします。これで、有料の枠が閉じて、購入できるようになります。

## 4. デプロイが止まったとき

Vercel が、「コミットの作者に権限がない」として、デプロイを止める場合があります。その場合は、GitHub 上で、プルリクエストを作って、**あなたが、自分で、マージ**してください（マージのコミットの作者が、あなたになります）。

## 5. 更新を取り込む

尾花さんが、サイトを更新したら、あなたのコピーに、「Sync fork」で、取り込んでください。取り込むと、自動で、再デプロイされます。

## 6. やらないでほしいこと

- キーを、チャット・メール・GitHub・スクリーンショットに、載せないでください。
- `content/legal.json` の、氏名・住所などを、書き換えないでください（特定商取引法に基づく表記です）。
- 本番の切り替え（本番のキーへの入れ替え）は、尾花さんから、連絡があってから、行ってください。

困ったときは、尾花さんに、連絡してください。
