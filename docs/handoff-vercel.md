## AI への指示（ここから下は、AI が読む部分）

あなたは、持ち主（人間）を手伝う AI です。次の規則を守って、手順 1 から順に進めてください。

### 規則

1. **キーや秘密の値を、画面（会話）に、表示しない・繰り返さない・ファイルに書かない。** Stripe のキー（`rk_…` / `sk_…`）は、人間が、Vercel の画面に、自分で貼り付けます。AI は、値を見ません。
2. **人間にしかできないこと**（下の「人間の作業」）は、AI が、代わりに、行わない。パスワード、本人確認、銀行口座、利用規約への同意、CAPTCHA、キーの貼り付けは、人間が行います。AI は、画面のどこを押すかを、1手ずつ、案内します。
3. **お金・公開に関わること**（本番の有効化、本番のキーへの入れ替え、`VITE_BILLING=1` の設定、`legal.json` の公開）の前に、人間に「実行していいですか」と確認する。
4. **ビルド・デプロイ**は、Vercel が自動で行います。手元で、勝手にビルドしない。
5. 各手順の最後に、「確認」を、実際に行い（URLを開く、ファイルを読む）、結果を、人間に、短く報告する。うまくいかないときは、原因を、先に調べて、推測で進めない。
6. 尾花さんへの連絡が必要なところは、連絡する内容を、そのまま送れる文章にして、人間に渡す。

### 人間の作業（AI は、代わりに、行わない）

## 0. 先に知っておくこと

- あなたが **販売事業者**（代金を受け取る人）になります。特定商取引法に基づく表記・利用規約・プライバシーポリシーに、あなたの情報が載ります。返金や問い合わせへの対応、売上の税務も、あなたの責任になります。
- 売上の分け方など、尾花さんとの取り決めは、先に話しておいてください。
- Vercel の料金は、あなたの負担です。

## 1. サイトを公開する（まず、課金なしで）

1. GitHub で、`haru516-web/chokan-uranai-web` を、自分のアカウントに **Fork**（コピー）します。（人間）
2. Vercel で、Add New → Project → コピーしたリポジトリを選び、**そのまま Deploy** します（Framework は Vite、設定は、自動で入ります）。（人間）
2-2. **AI が、ファイルを編集できるように、コピーしたリポジトリを、手元に clone する。** `git clone https://github.com/あなたのアカウント/chokan-uranai-web.git` を実行し、そのフォルダで、AI を動かす。以降の、ファイルの編集・コミット・プッシュは、そのフォルダで、行う（プッシュすると、Vercel が、自動で、再デプロイします）。
3. **確認**（AI が行う）：公開URLについて、次を開く。
   - `/`、`/questions/`、`/about/`、`/terms/`、`/privacy/`、`/tokushoho/`、`/refund/` が、開く
   - `/sitemap.xml`、`/robots.txt` が、開く
   - `/api/config` が `{"billing":false,…}` を返す（この段階では、課金は、まだ動きません）
4. 公開URLを、尾花さんに、連絡する。

## 2. Stripe を準備する（まず、テスト用の環境で）

Stripe のダッシュボードで、テスト用の環境（サンドボックス）に切り替えて、次を行います。（人間。AI は、画面の案内をする。Stripe CLI を、人間が `stripe login` したあとなら、手順1は、AI が CLI で行ってもよい）

1. **商品を作る**：商品カタログ → 商品を追加。
   - 名前：`潮環占い プレミアム`
   - 価格：**定期支払い・月額 450円**（日本円）
   - 作った価格のID（`price_…`）を、控える。
2. **カスタマーポータルを有効にする**：設定 → 請求 → カスタマーポータル。「サブスクリプションのキャンセル」を許可する（利用者が、解約を自分で行うページになります）。
3. **キーを作る**：開発者 → APIキー → 制限付きのキーを作成（`rk_test_…`）。次の権限だけを与える。

| 権限 | 内容 |
|---|---|
| Checkout Sessions | 書き込み |
| Customer portal | 書き込み |
| Subscriptions | 読み取り |
| Customers | 読み取り |

キーは、この時点で、AI に見せず、次の手順で、Vercel に、直接、貼ります。

## 3. 販売事業者の情報を入れる

リポジトリ（あなたのコピー）の `content/legal.json` の `operator` を、最初に聞いた情報で埋めます。AI が、ファイルを編集して、コミット・プッシュしてよい（人間に、内容を見せて、確認してから）。

| 項目 | 入れるもの |
|---|---|
| `name` | 販売事業者の名前（個人なら、氏名） |
| `representative` | 運営統括責任者（個人なら、氏名） |
| `address` | 住所 |
| `phone` | 電話番号 |
| `email` | 問い合わせ用のメール |

- `operator` 以外（`plan`、`dates`、`court`）は、**触らない**。
- 空欄のところは、ページに「未記入」と目立つ形で出ます。**有料版を始める前に、すべて埋める。**
- **確認**（AI）：`/tokushoho/`、`/terms/`、`/privacy/` に、「未記入」が、残っていない。

### 3-2. 規約・返金方針・プライバシーを、読んで、同意する

あなたが販売事業者になるので、サイトに載る文面は、あなたの約束になります。AI は、次の3ページの全文を、人間に、読める形で見せ（または、要点を、まとめて）、**人間が、同意したことを、確認する。** 同意できない点があれば、尾花さんに、連絡する（AI は、勝手に、文面を書き換えない）。

- `/terms/`（利用規約）：解約のしかた、免責など
- `/refund/`（返金の方針）：返金できる場合と、できない場合
- `/privacy/`（プライバシーポリシー）：集める情報（購入のトークンなど）と、使い道。ホスティングは Vercel、決済は Stripe と、書いてある

## 4. 有料版を動かす（テスト用の環境で、先に確認）

Vercel の Settings → Environment Variables に、次を入れます。**値は、保存したあと、見えなくなる「Sensitive」にする。** 環境は、Production と Preview の、両方にチェックを入れます。

| 名前 | 値 | 誰が入れる |
|---|---|---|
| `STRIPE_SECRET_KEY` | 手順2で作ったキー（`rk_test_…`） | 人間が、貼る |
| `STRIPE_PRICE_ID` | 手順2で控えた価格のID（`price_…`） | 人間（または、AI の案内で） |
| `ENTITLEMENT_SECRET` | 長いランダムな文字列（32文字以上） | 下記 |

`ENTITLEMENT_SECRET`：AI は、値を、会話に出さずに、生成して、Vercel に入れてよい。Vercel CLI を使う場合の例（人間が `vercel login` と `vercel link` を済ませたあと）：

```
node -e "process.stdout.write(require('crypto').randomBytes(32).toString('hex'))" | vercel env add ENTITLEMENT_SECRET production
```

CLI が使いにくい場合は、人間が、`openssl rand -hex 32` などで作って、画面に貼ってもよい（Preview にも入れる）。

入れたら、**まず `VITE_BILLING` は、入れずに**、再デプロイします（Deployments → 最新の「…」→ Redeploy）。

**確認**（AI）：
1. `/api/config` が `{"billing":true,…}` を返す。
2. 有料の枠が、まだ、すべて開いたままである（`VITE_BILLING` が、ないため）。
3. 尾花さんに、「ここまで済みました」と連絡する。

## 5. 有料の枠を閉じて、テストする

1. 人間に確認してから、`VITE_BILLING` に `1` を入れて、再デプロイする（`VITE_BILLING` は、ビルドのときに読まれるので、入れたあとの再デプロイが要ります）。
2. 設定画面（右上の歯車）から、申し込む。テストカードは `4242 4242 4242 4242`（期限は、未来の日付、CVC は、適当な3桁）。（人間が操作。AI は、案内する）
3. **確認**：有料の枠が、開く。
4. 管理ページから、解約する。**確認**：枠が、閉じる。
5. 結果を、尾花さんに、連絡する。

## 6. 本番に切り替える

テストが通って、手順3も埋まっていて、人間が「本番に進む」と言ったら、Stripe を **本番の環境**に切り替えて、手順2をもう一度行う（テスト用の商品・価格・キーは、本番では使えません）。

1. 本番で、商品（`潮環占い プレミアム`、月額450円）を作り、価格のIDを控える。
2. 本番で、カスタマーポータルを有効にする。
3. 本番で、制限付きのキー（`rk_live_…`）を作る（権限は、手順2と同じ）。
4. Vercel の `STRIPE_SECRET_KEY` と `STRIPE_PRICE_ID` を、本番のものに入れ替えて、再デプロイする。
5. 本番で、一度、自分で申し込んで、解約する（少額の実費がかかる。解約・返金のやり方を、先に確認する）。

## 7. 公開後の運用

- **問い合わせ**：`legal.json` の `email` に、利用者から、申込み・解約・返金の連絡が来る。人間が、返信する（AI は、返信の下書きを、作ってよい。送るのは、人間）。
- **返金のしかた**：Stripe ダッシュボード → 支払い → 該当の支払い → 返金。返金の方針（`/refund/`）に、沿って行う。
- **解約**：利用者が、設定画面の管理ページから、自分で行う。Stripe ダッシュボードの「サブスクリプション」からも、確認・解約できる。
- **売上の確認**：Stripe ダッシュボードで、確認する。税務は、あなたの責任で、行う。

## 8. 独自ドメインを使うとき（使わないなら、飛ばす）

1. Vercel の Settings → Domains で、ドメインを追加して、案内のとおりに、DNS を設定する。（人間）
2. 環境変数 `SITE_URL` に、`https://あなたのドメイン/`（最後に `/`）を入れて、再デプロイする。サイトマップや検索用のURLが、そのドメインになる。
3. **確認**（AI）：`/sitemap.xml` のURLが、そのドメインになっている。
4. 新しいURLを、尾花さんに、連絡する（検索サイト側の登録のやり直しが、要るため）。

## 9. 検索サイトへの登録（Search Console）

公開URLが決まって、サイトが公開されたら、行います。独自ドメインを使う場合は、手順8のあとに行う。

1. **潮環占い専用の Gmail**（尾花さんと、共有しているもの）で、Search Console（https://search.google.com/search-console）を開き、「プロパティを追加」→「URL プレフィックス」で、公開URLを入れる。（人間）
2. 所有権の確認は、リポジトリの `public/` に、確認用ファイルを足す方法が、簡単。AI は、次を行う：
   - 人間に、Search Console の「HTML ファイル」の確認で、`googleXXXX.html` を、ダウンロードしてもらう（まだ「確認」は、押さない）。
   - そのファイルを、リポジトリの `public/` に置いて、コミット・プッシュする。デプロイされたら、`https://公開URL/googleXXXX.html` が開くことを、確認する。
   - 人間が、Search Console で、「確認」を押す。
   - リポジトリに、すでにある `public/google6b57….html` と `public/googledc7e….html` は、前の持ち主のものなので、触らない。
3. 確認できたら、サイトマップ `/sitemap.xml` を、送信する。（人間）
4. 更新の取り込み（手順10）で、`public/` の確認用ファイルが、ぶつかったら、あなたのファイルを、残す。

## 10. 困ったとき・更新

- **デプロイが止まる**：Vercel が、「コミットの作者に権限がない」として、止める場合がある。GitHub 上で、プルリクエストを作って、**人間が、自分で、マージ**する（マージのコミットの作者が、人間になります）。
- **更新の取り込み**：尾花さんが、サイトを更新したら、コピーに、「Sync fork」で取り込む。自動で、再デプロイされる。`content/legal.json` で、ぶつかったら、**`operator` は、あなたの内容を残す**。
- **やらないでほしいこと**：キーを、チャット・メール・GitHub・スクリーンショットに、載せない。`operator` 以外の `legal.json` を、書き換えない。手順5のテストが通る前に、本番へ、切り替えない。

困ったときは、尾花さんに、連絡してください。

## 参考：このリポジトリの事実（AI が、迷ったときに）

- 環境変数の一覧は `.env.example`。使うのは `STRIPE_SECRET_KEY`、`STRIPE_PRICE_ID`、`ENTITLEMENT_SECRET`、`VITE_BILLING`（ビルド時に読まれる）。`SITE_URL` は、独自ドメインのときだけ。
