# 尾花さん側の作業（向こうに頼まず、自分で行うこと）

向こうへ渡すのは `docs/handoff-vercel.md` です。Stripe、Vercel、Search Console は、向こうに任せます。このファイルは、尾花さん自身の、やることのまとめです。

## 向こうに、先に伝えること

- 売上の分け方など、取り決め。

## 向こうからの連絡に合わせて

| 向こうからの連絡 | こちらの対応 |
|---|---|
| 公開URLを連絡 | 特になし（Search Console は、共有している専用の Gmail で、向こうが行う） |
| 「ここまで済みました」（手順4） | 特になし。テストの結果を待つ |
| テストの結果（手順5） | 通っていれば、「本番に進んでよい」と返す |
| 規約などに、同意できない点がある（手順3-2） | 文面を直す（`content/legal.json` や `scripts/site/` の文面を変更して、プッシュ） |
| Sync fork で、ぶつかった | `operator` と、`public/` の確認用ファイルは、向こうの内容を残すよう、伝える |

## 更新するとき

サイトを更新して、`main` に反映したら、向こうに、「Sync fork して」と、連絡する。
